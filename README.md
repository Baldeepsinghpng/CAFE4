# Demo 4: NOISY BEAN (Trendy Gen-Z Cafe)

Bold, loud, social-media-friendly. **Fictional demo brand. Every detail is a placeholder.**

## Preview
Double-click `index.html`.

## Change the basics
- **Name, WhatsApp number, intro message, currency, map:** `CONFIG` block at the top of `script.js`.
- **Menu items:** each product card in `index.html` has `data-name` and `data-price`. Change those **and** the visible text. The order list reads `data-name` / `data-price`.
- **Colours:** variables at the top of `style.css` (`--red`, `--lime`, `--pink`).
- **Photos:** search for `images.unsplash.com`.
- **Feed section:** posts are placeholders and link nowhere. Replace with the real Instagram handle or remove them.

## How the order list works
Customers tap "+ Add", then "Send on WhatsApp". That opens WhatsApp with the order typed out. It is just a link. **There is no payment, stock check or order system.** The cafe must confirm each order manually.
